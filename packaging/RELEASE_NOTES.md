## Download

| System | File |
| --- | --- |
| Mac with Apple silicon (M1 or newer) | `Crater-macOS-AppleSilicon.dmg` |
| Intel Mac | `Crater-macOS-Intel.dmg` |
| Windows 10 / 11 | `Crater-Windows-Setup.exe` (installer) or `Crater-Windows.zip` (portable) |

**macOS:** open the DMG and drag Crater into Applications. The app is not yet
notarized by Apple, so the first launch is blocked: open **System Settings →
Privacy & Security** and click **Open Anyway** (or right-click Crater → Open).

**Windows:** run the installer. If SmartScreen appears, choose **More info →
Run anyway** (the app is not yet code-signed).

See the README for the workflow and the measurement method.
